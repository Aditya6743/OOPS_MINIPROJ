# Objectives

1. **Automate Banking Operations:** Provide an intuitive interface for account creation, deposits, withdrawals, and transfers.
2. **Implement Business Logic securely:** Enforce validation rules (e.g., preventing negative deposits and checking overdraft limits) using Java Exceptions.
3. **Persist Data Reliably:** Store all account details and transactions in structured text files to ensure data is retained across application restarts.
4. **Demonstrate OOP Principles:** Utilize Encapsulation, Inheritance, Polymorphism, and Abstraction to structure the codebase logically.
